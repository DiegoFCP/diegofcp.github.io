# diegofcp.github.io

Portafolio personal de **Diego Cortés Pinilla**, Software Developer Full Stack (Santiago, Chile).

Sitio estático (HTML + CSS + un poco de JavaScript vanilla), sin build step, publicado con GitHub Pages en https://diegofcp.github.io

## Archivos
- `index.html`: el sitio completo (estilos y script inline, favicon SVG inline).
- `assets/og.png`: imagen para vistas previas al compartir el enlace (Open Graph, 1200×630).

## Publicar
Sube estos archivos a la rama `main` del repo `DiegoFCP/diegofcp.github.io` y activa GitHub Pages (Settings → Pages → Deploy from a branch → `main` / root).
